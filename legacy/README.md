# 戦国めもりー

武将とゆかりのお宝をそろえる、日本語の神経衰弱ゲームです。HTML・CSS・JavaScriptのみで動作し、インストールやインターネット接続は不要です。

## パソコンでの起動方法

1. このフォルダーの `index.html` をダブルクリックしてください。
2. Chrome、Safari、Edge、Firefoxなどの新しいブラウザーで開くと遊べます。

`index.html`、`style.css`、`game.js` は同じフォルダーに置いてください。

## スマホで遊ぶ方法

Webサーバーに3つのファイルを同じ場所にアップロードし、そのURLをスマホのブラウザーで開いてください。

自宅の同じWi-Fiで確認する場合は、Python 3が入ったパソコンで、このフォルダーをターミナルで開き、次を実行します。

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

パソコンでは `http://localhost:8000`、スマホでは `http://パソコンのローカルIPアドレス:8000` を開きます。IPアドレスはパソコンのネットワーク設定で確認できます。ファイアウォールの確認が出た場合は自宅のネットワークで接続を許可してください。終了はターミナルで Ctrl+C を押します。

## ルール

- 10枚のカードから「武将」と「ゆかりのお宝」のペアを探します。
- 織田信長 × 安土城
- 豊臣秀吉 × 金の茶室
- 徳川家康 × 江戸城
- 武田信玄 × 風林火山の旗
- 上杉謙信 × 毘の旗
- ペアがそろうと3択の歴史クイズが出ます。間違えた場合は解説をヒントに再挑戦できます。
- 正解すると家紋を獲得。5つ集めると天下統一です。
- 「はじめから」でカードをシャッフルしてリセットできます。
- 進行状況は保存されません。ページを閉じたり再読み込みしたりすると最初からになります。

イラストはオリジナルのSVGです。家紋は学習ゲーム向けの簡略図で、厳密な紋様の再現ではありません。外部フォント・外部画像・外部ライブラリーを使用していません。
