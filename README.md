# 戦国めもりーRPG

5人の戦国武将と、10の歴史冒険に出かける神経衰弱ゲームです。
基準画像 `assets/game-design.png` をもとに、桜・赤・金・紺のアニメRPGの世界に改修しました。

## いちばん簡単な起動方法（パソコン）

1. このフォルダーの **index.html をダブルクリック**します。
2. Chrome、Safari、Edge、Firefoxなどの新しいブラウザーで開きます。
3. 「冒険をはじめる」を押してください。

インストール、会員登録、インターネット接続は必要ありません。以前の画面が出る場合はブラウザーを再読み込みしてください。ファイルを移す場合は、このフォルダー全体をまとめて移してください。

## スマホで遊ぶ方法

画像とプログラムを含むフォルダー全体を静的Webサーバーに置き、そのURLをスマホで開きます。ゲーム自体はサーバー側の処理や外部APIを使いません。

自宅で同じWi-Fiにつないで確認するときは、Python 3が入ったパソコンでこのフォルダーをターミナルで開き、次を実行します。

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

- パソコン：`http://localhost:8000`
- スマホ：`http://パソコンのローカルIPアドレス:8000`

IPアドレスはパソコンのネットワーク設定で確認できます。終了はターミナルで Ctrl+C。Pythonが入っていない場合、パソコンで遊ぶだけなら上のダブルクリックで十分です。

## 遊び方

- 武将のカードと、その武将のゆかりカードを2枚そろえます。
- ゆかりカードの上には「織田家ゆかり」などの目印があります。同じ合戦に複数の武将が参加しているため、どの武将の物語かを示しています。
- 同じ武将のカードが複数ある場合、その武将に対応するゆかりカードのどれとでもペアになります。
- ペア成立後は、その武将の3択クイズ。正解すると家紋を獲得します。
- まちがえたら正しい答えと解説を読み、もう一度答えられます。
- 全ペアのクイズに正解するとステージクリア。次のステージが開きます。
- 初回クリアだけ100ポイント。再挑戦で重複加算されず、合計は1000ポイントです。
- レベル10をクリアすると「天下統一の証」を獲得し、特別な宝箱を開けられます。宝箱演出は図鑑から何度でも再生できます。
- 「組み合わせ表」でそのステージのヒントを確認できます。
- 音は右上の「音」から音量調節・ミュートできます。最初のボタン操作のあとに音が始まります。

## 10ステージ

| レベル | テーマ | カード枚数 |
|---|---|---:|
| 1 | 戦国武将の名前 | 10 |
| 2 | 武将とお城 | 12 |
| 3 | 家紋と旗印 | 14 |
| 4 | 戦国時代の道具 | 16 |
| 5 | 有名な合戦 | 18 |
| 6 | 武将の人間関係 | 20 |
| 7 | 戦国時代の出来事 | 22 |
| 8 | 領地と日本地理 | 24 |
| 9 | 歴史の順番と戦略 | 26 |
| 10 | 天下統一への最終決戦 | 28 |

クイズは100問。各章に武将別の問題を用意し、出題履歴を保存します。カードが多い章では直前の章などの同じ武将の問題も交えて復習します。同じステージ内では同じ問題を繰り返さない構成です。選択肢の並びとカード配置も毎回変わります。レベル10は年代比較、因果関係、史料と伝説の違いなどを扱います。

## 自動保存について

ポイント、クリア済みステージ、家紋、天下統一の証、途中のカード配置と成立済みペア、クイズ、出題履歴、音量設定を、ブラウザーの localStorage に保存します。途中ならタイトルの「途中から再開」で続けられます。めくりかけの未成立カードは裏に戻ります。

同じ端末・同じブラウザー・同じURLで再開してください。ファイルの保存場所やURLを変えた場合、別の記録になることがあります。プライベートブラウズやブラウザーデータの削除では記録が失われることがあります。保存できない環境では画面下に表示します。

## お城の成長

100pt：小さな砦 → 300pt：城門と城壁 → 500pt：天守 → 700pt：城下町 → 1000pt：天下統一の大城郭。専用の6段階の画像（開始前を含む）で見た目が変わります。

## 素材と、まだ確認が必要なもの

5人のキャラクター、背景、お城、城・旗・道具、開封前後の宝箱は、基準画像を参照して新規生成した素材です。文字や他キャラクターが混ざる切り抜きは使っていません。同じ武将は全画面で同じファイルを使います。

**正確な家紋の原図は未導入です。** 現在は紋の名称と「仮画像・図案未検証」を表示しています。キャラクター・旗・宝箱の装飾紋は創作であり、正式な家紋の見本ではありません。史料で図案と利用条件を確認した画像に差し替えてから正式扱いにしてください。

建物の絵は創作イラストで、往時の建築を厳密に復元したものではありません。人物・出来事・道具の一部のカードは共通の絵地図を飾りとして使い、正確な関係はカード名で示します。専用画像を増やすための一覧は [ASSETS.md](ASSETS.md) を参照してください。

BGM・効果音はWeb Audio APIで合成するオリジナル音です。外部音楽・既存楽曲・画像配信サービス・外部フォントは使用していません。生成画像の出自と学習内容の参考資料は [SOURCES.md](SOURCES.md) に記載しました。

## ファイルの役割

- `index.html`：ゲームの入り口
- `style.css`：画面、スマホ対応、演出
- `data.js`：武将紹介、100問のクイズ、各章のカード候補、画像パス
- `engine.js`：ステージ、ポイント、出題履歴、保存処理
- `game.js`：画面と操作、クイズ、宝箱の演出
- `audio.js`：BGMと9種類の効果音
- `assets/`：画像素材。差し替え先は `ASSETS.md` に記載
- `legacy/`：改修前の版。`legacy/index.html` を開くと元のゲームが遊べます
- `tests/`：ゲーム処理と画面遷移、音声処理の自動チェック

## 動作確認の範囲

Node.jsが入った環境では次の3つを実行できます。

```sh
node tests/engine.test.cjs
node tests/ui-flow.test.cjs
node tests/audio.test.cjs
```

確認済み：全10ステージ・95ペアのクリア処理、クイズ誤答→再挑戦→正解、1000pt到達と重複加点防止、5人の家紋獲得、保存と復元、お城の成長、宝箱の揺れ・光・開封・小判・米俵・祝福・スキップ、音量・ミュート・音の発音命令、参照画像の存在。

**DOMハーネスによるプログラム検証です。実ブラウザーの描画・タッチ操作・3D表現と、実機での音の試聴は未確認です。** 制作環境ではローカルファイルのブラウザー操作を利用できなかったためです。スマホ・パソコンで公開前に表示と音量を確認してください。
